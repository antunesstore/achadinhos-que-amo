# Achadinhos que Amo

Site profissional de afiliados para reunir ofertas de Shopee, Shein, Mercado Livre e Amazon em uma vitrine moderna, responsiva e fácil de navegar.

## Recursos

- Vitrine de produtos por marketplace
- Busca e filtros de ofertas
- Favoritos no navegador
- Seção de promoções em destaque
- Painel administrativo simples
- Layout responsivo para desktop e celular

## Tecnologias

- HTML
- CSS
- JavaScript
- Supabase
